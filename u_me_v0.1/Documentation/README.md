# U&Me iOS Application

## Architecture
This project follows Clean Architecture with MVVM presentation layer.

## Project Structure
- `Sources/` - All source code
  - `App/` - Application entry point and configuration
  - `Core/` - Business logic and data layer
  - `DesignSystem/` - Reusable UI components
  - `Features/` - Feature modules
  - `Shared/` - Shared utilities
  - `Infrastructure/` - Technical infrastructure
  - `Platform/` - Third-party integrations

- `Resources/` - Assets, localization, fonts
- `Tests/` - All test suites
- `Configuration/` - Build configurations
- `Documentation/` - Project documentation
